# 编辑器与调试功能

当前编辑器参考 IntelliJ 的常用操作方式，提供补全、参数提示、快速文档、代码导航、重构预览和调试。具体语言能力由已连接的语言服务器（LSP）或 Monaco 内置服务提供，不宣称与完整 IntelliJ IDEA 功能对等。

## 常用快捷键

以下快捷键在代码编辑器获得焦点时生效；菜单入口位于编辑区上方。

| 操作 | Windows / Linux 快捷键 |
| --- | --- |
| 代码补全 | `Ctrl+Space` |
| 参数信息 | `Ctrl+P` |
| 快速文档 | `Ctrl+Q` |
| 跳转到定义 | `Ctrl+B` |
| 预览定义 | `Ctrl+Shift+I` |
| 跳转到实现 | `Ctrl+Alt+B` |
| 查找引用 | `Alt+F7` |
| 文件结构 | `Ctrl+F12` |
| 重命名符号 | `Shift+F6` |
| 快速修复 | `Alt+Enter` |
| 重构选中代码 | `Ctrl+Alt+Shift+T` |
| 整理导入 | `Ctrl+Alt+O` |
| 整理格式 | `Ctrl+Alt+L` |

“代码导航”菜单还提供跳转到类型、调用层级和类型层级。编辑器之外，`Ctrl+P` 继续打开全局项目搜索，`Ctrl+B` 继续切换文件侧栏。

操作会根据语言服务能力、文件只读状态和当前处理状态启用或禁用，并说明原因。只读文件允许查看文档、定义和引用；补全插入、重命名、修复、重构及整理格式等修改操作会被阻止。具体重构选项取决于语言服务实际返回的内容。

## 中文悬停与快速文档

接入项目 LSP 的悬停默认展示中文说明，保留原有作用解释、业务信息、返回类型、识别依据和翻译状态。声明签名、类型、标识符与代码保持原文。翻译尚未准备好或失败时显示相应状态，不将英文原文冒充已完成的中文翻译。

按 `Ctrl+Q` 或通过“代码导航 → 快速文档”查看完整内容。面板提供所属包或类型信息、声明签名、可滚动的完整说明、复制签名与可点击参考链接。存在服务器原文时，可主动切换“中文说明／原文”；默认仍为中文。原有中文增强内容不会被原文替换。

点击“固定说明”后，切换文件仍保留原符号的文档，方便对照代码。关闭按钮和 `Esc` 可关闭面板。纯文本保持字面内容；服务器文档中的命令链接和原始 HTML 不执行，图片不自动加载。

未接入 LSP 的 Monaco 内置文档不保证中文；当前中文文档处理不覆盖所有内置语言服务。

## 重构与修改预览

补全支持语言服务返回的代码片段、参数占位和自动导入。跨文件重命名及代码操作进入“代码修改预览”，展示受影响文件，确认后应用到草稿，不直接写入磁盘。整批修改可撤销，保存仍由用户明确执行。整理格式同样作用于草稿并支持撤销。

## 调试

沿用现有 Python（debugpy）和 Java 的 DAP 调试能力，包括断点、继续、单步、调用栈和变量查看；可用环境以项目检测结果为准。

新增表达式求值与监视列表。求值使用当前暂停位置和选中栈帧，支持查看对象的子变量。监视表达式在加入列表、进入新的暂停状态或切换栈帧时求值；普通状态轮询不会反复执行表达式。程序运行中暂停求值，过期暂停状态或旧栈帧的返回结果不会覆盖当前结果。
